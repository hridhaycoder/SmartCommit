# SmartCommit

This is a smart commiter using small AI models to help me figure out an easy way to make commits descriptive. This is especially useful for public projects where people need descriptive and concise commits to approve merges and pr's. Later once I finish working on this I want to publish this as a python project for people to use so others can just download to with pip, starting from version 3.10. I also want to make it have more colors and be more interactive
